# CorelDRAW AI Agent

Een volledig conversationele AI-agent die zowel CorelDRAW als Blender kan aansturen via natuurlijke taalinteractie. De agent is in staat alle communicatie uit te voeren en te vertalen naar de juiste acties binnen de ontwerpsoftware, zonder afhankelijk te zijn van vooraf gedefinieerde commando's.

## Projectoverzicht

De AI Design Agent maakt gebruik van lokale Ollama LLM-modellen voor offline functionaliteit en privacy, en implementeert een architectuur met de volgende componenten:

- **Browser Client**: React + Tailwind + R3F/Three.js 
- **API Gateway / WebSocket Server**: Node.js/Python met bidirectionele communicatie
- **Orchestrator Service**: Multi-model benadering met intent routing, code generatie en validatie
- **Software Integraties**: Zowel Blender (Python) als CorelDRAW (COM/VSTA)

## Installatie

### Ontwikkelomgeving vereisten

- Node.js (v18+)
- Python (v3.10+)
- Docker + Docker Compose
- Git
- Visual Studio Code (aanbevolen)

### Ollama Setup

1. Download en installeer Ollama van [ollama.com](https://ollama.com/download)
2. Pull de benodigde LLM-modellen:
   ```bash
   ollama pull llama3.2:11b-q4_K_M   # Intent router
   ollama pull codeqwen:14b-q4_K_M   # Code generator  
   ollama pull deepseek-coder:7b-q4_K_M  # Validatie (optioneel)
   ```

### Docker containers starten

```bash
# Clone de repository
git clone [repository-url]
cd ai-corelapp01

# Start de containerized omgeving
docker-compose up -d
```

## Ontwikkeling

Het project wordt ontwikkeld volgens het implementatieplan beschreven in `CorelDRAW-AI-Agent-Stappenplan.md`, dat een gedetailleerde fasering bevat van alle componenten en mijlpalen.

### Core Componenten

- **Front-end**: Next.js, React, Tailwind, shadcn/ui
- **API Gateway**: NestJS of FastAPI met WebSockets
- **Data Management**: ChromaDB voor vector embeddings
- **LLM Management**: Ollama API integratie
- **Software Integraties**: Python scripts en COM automation

### Projectstructuur

```

│   └── validation/       # Code validation
├── integrations/         # Software integraties
│   ├── blender/          # Blender Python API integratie
│   └── coreldraw/        # CorelDRAW COM/VSTA integratie
├── docker/               # Docker configuratie
├── docs/                 # Documentatie
└── docker-compose.yml    # Containerorchestration
```
