# CorelDRAW AI Agent

Een volledig conversationele AI-agent die zowel CorelDRAW als Blender kan aansturen via natuurlijke taalinteractie. De agent is in staat alle communicatie uit te voeren en te vertalen naar de juiste acties binnen de ontwerpsoftware, zonder afhankelijk te zijn van vooraf gedefinieerde commando's.

## Projectoverzicht

De AI Design Agent maakt gebruik van lokale Ollama LLM-modellen voor offline functionaliteit en privacy, en implementeert een architectuur met de volgende componenten:

- **Browser Client**: React + Tailwind + R3F/Three.js 
- **API Gateway / WebSocket Server**: Node.js/Python met bidirectionele communicatie
- **Orchestrator Service**: Multi-model benadering met intent routing, code generatie en validatie
- **Software Integraties**: Zowel Blender (Python) als CorelDRAW (COM/VSTA)

## Installatie

### Ontwikkelomgeving vereisten

- Node.js (v18+)
- Python (v3.10+)
- Docker + Docker Compose
- Git
- Visual Studio Code (aanbevolen)

### Ollama Setup

1. Download en installeer Ollama van [ollama.com](https://ollama.com/download)
2. Pull de benodigde LLM-modellen:
   ```bash
   ollama pull llama3.2:11b-q4_K_M   # Intent router
   ollama pull codeqwen:14b-q4_K_M   # Code generator  
   ollama pull deepseek-coder:7b-q4_K_M  # Validatie (optioneel)
   ```

### Docker containers starten

```bash
# Clone de repository
git clone [repository-url]
cd ai-corelapp01

# Start de containerized omgeving
docker-compose up -d
```

## Quick Start

### Opstart Scripts
Het project bevat opstart scripts om de applicatie eenvoudig te starten:

**Windows:**
```
start.bat
```

**Linux/Mac:**
```
chmod +x start.sh
./start.sh
```

Deze scripts voeren de volgende taken uit:
- Controleren of Docker en Ollama geïnstalleerd zijn
- `.env` bestanden aanmaken indien nodig
- Docker containers opstarten
- Controleren of de server bereikbaar is
- Ollama modellen status controleren
- De frontend openen in de browser

### Stop Scripts
Om de applicatie te stoppen zijn er ook handige scripts beschikbaar:

**Windows:**
```
stop.bat
```

**Linux/Mac:**
```
chmod +x stop.sh
./stop.sh
```

Deze scripts voeren de volgende taken uit:
- Controleren of er actieve containers zijn
- Docker containers netjes afsluiten
- Optie om persistent data (volumes) te verwijderen

### Handmatige Installatie
Als alternatief kan je de applicatie ook handmatig starten:

1. Zorg dat Docker geïnstalleerd is
2. Maak `.env` bestanden aan in de `client` en `server` mappen
3. Start de containers:
   ```
   docker-compose up -d
   ```
4. Open de browser op http://localhost:3001

## Geïmplementeerde Functionaliteiten

### Software Command Services

De applicatie bevat nu een uitgebreide command service structuur voor het aansturen van zowel CorelDRAW als Blender:

- **SoftwareCommandService**: De hoofdservice die commands coördineert en routeert naar de juiste softwarepakketten.
  - Ondersteunt meerdere platforms (CorelDRAW, Blender)
  - Centraliseert error handling en logging
  - Biedt een uniform interface voor het uitvoeren van acties

- **CorelDrawCommandsService**: Specifieke commands voor CorelDRAW:
  - Vormen maken: rechthoeken, ellipsen, tekst
  - Objecten selecteren op basis van criteria
  - Elementen bewerken (kleur, positie, rotatie)
  - Tekst en lettertypes manipuleren

- **BlenderCommandsService**: Specifieke commands voor Blender:
  - 3D-objecten maken: kubussen, cylinders, vlakken
  - Materialen en texturen toepassen
  - Camera-instellingen aanpassen
  - Objecten transformeren (schalen, roteren, verplaatsen)

- **CommandFactoryService**: Integreert de verschillende command services:
  - Dynamic command routing op basis van platform en actie
  - Gestandaardiseerde parameter validatie
  - Transparante error handling

Deze architectuur zorgt voor een flexibele en uitbreidbare basis voor het toevoegen van nieuwe commands en integraties met andere ontwerptools in de toekomst.

# Chat Geheugen Systeem

Dit is een eenvoudig systeem om chatgesprekken automatisch bij te houden, zodat de AI-assistent een permanent geheugen heeft van jullie conversaties.

## Functionaliteiten

- 🔄 **Automatische opslag**: Slaat gesprekken elke minuut automatisch op
- 📦 **Backups**: Maakt elke 10 minuten een backup
- 📝 **Conversatiebehoud**: Bewaart context over meerdere gesprekken heen
- 👁️ **Monitoring**: Bekijk op elk moment de inhoud van het geheugen

## Bestanden

- `auto-chat-memory.js` - Hoofdprogramma voor het bijhouden van gesprekken
- `show-memory.js` - Tool om de opgeslagen gesprekken te bekijken
- `start-memory.bat` - Start het chatgeheugen-systeem (Windows)
- `show-memory.bat` - Bekijk de huidige staat van het geheugen (Windows)
- `watch-memory.bat` - Bekijk het geheugen continu, updates elke 30 seconden (Windows)

## Benodigdheden

- Node.js (https://nodejs.org/) - Versie 12 of hoger

## Gebruik

1. **Start het chatgeheugen-systeem**:
   - Windows: Dubbelklik op `start-memory.bat`
   - Unix/Mac: `node auto-chat-memory.js`

2. **Voer gesprekken in**:
   - `USER: [bericht]` - Voeg een gebruikersbericht toe
   - `AI: [bericht]` - Voeg een AI-assistent bericht toe
   - Je kunt ook direct tekst invoeren (wordt als gebruikersbericht opgeslagen)

3. **Beheer commando's**:
   - `SHOW` - Toon de huidige conversatie
   - `BACKUP` - Maak handmatig een backup
   - `EXIT` - Sluit het programma af

4. **Bekijk het geheugen** (apart venster):
   - Windows: Dubbelklik op `show-memory.bat`
   - Unix/Mac: `node show-memory.js`

5. **Monitor het geheugen continu** (apart venster):
   - Windows: Dubbelklik op `watch-memory.bat`
   - Unix/Mac: `node show-memory.js --watch`

## Opslag

Alle gegevens worden opgeslagen in de map `./chat-memory`:
- `ongoing-conversation.json` - Het huidige actieve geheugen
- `backup-[datum-tijd].json` - Automatische backups (maximaal 10 worden bewaard)

## Tips

- Laat het hoofdprogramma (`auto-chat-memory.js`) draaien in een apart venster tijdens het chatten
- Gebruik `watch-memory.bat` in een ander venster om te zien wat er is opgeslagen
- Voeg regelmatig zowel gebruikersberichten als AI-berichten toe om het gesprek volledig vast te leggen
