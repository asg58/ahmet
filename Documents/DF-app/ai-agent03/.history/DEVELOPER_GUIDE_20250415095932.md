# Blender WebSocket Project - Developer Guide

## Quickstart
```bash
# 1. Start de Blender WebSocket server
"C:\Program Files\Blender Foundation\Blender 4.4\blender.exe" -b -P blender_agent/websocket_server.py

# 2. Voer een client script uit om te testen
python test_client.py
```

## Projectdoel
Dit project biedt een WebSocket-gebaseerde communicatie tussen externe applicaties en Blender. Het stelt je in staat om Blender op afstand aan te sturen zonder de GUI te gebruiken, wat ideaal is voor automatisering, batch processing en integratie met web-interfaces.

## Kerncomponenten & Dataflow

```
[Externe Client]  <--- WebSocket (JSON) --->  [Blender WebSocket Server]  --->  [Blender Engine]
     |                                                                             ^
     |                                                                             |
     v                                                                             |
[Dashboard UI]  <----  REST API/WebSocket  ----  [ChromaDB] ---- Model indexering -|
```

### 1. Core Module: WebSocket Server (`blender_agent/websocket_server.py`)
- Endpoint: `ws://localhost:8765`
- Protocol: JSON berichten met `{"type": "bpy_script", "code": "import bpy..."}` formaat
- Functie: Ontvangt Python/bpy code, voert deze uit in Blender, stuurt JSON respons terug

### 2. Client Scripts (`test_client.py`, `create_*.py`)
- Verbinden met WebSocket server
- Sturen Blender Python code als string
- Verwerken respons (succes/fout)
- Volgen consistent patroon uit `blender_client_lib.py`

### 3. Dashboard Web App (`dashboard/`)
- React frontend + Three.js voor 3D visualisatie
- Verbindt met Blender WebSocket server
- Biedt modelmanagement en chat-interface

### 4. Vector Database (`blender_chroma_db.py`)
- Semantisch zoeken van 3D modellen
- Indexeert .blend bestanden met metadata
- Integreert met dashboard voor modelmanagement

## Interne Werking & Conventies

### Client Script Pattern
Elk client script volgt dit patroon:
1. `send_bpy_script()` functie voor communicatie
2. `main()` functie met Blender code als multi-line string
3. Platform-specifieke asyncio configuratie

### Code Uitvoering
```
[Client script] --> [WebSocket] --> [Server] --> [exec() in Blender context] --> [Resultaat] --> [JSON Response]
```

### Checkpointsysteem
- `create_checkpoint.py`: Maakt snapshot van huidige projectstatus
- `checkpoints/`: Bevat alle historische project-versies
- Elk checkpoint bevat metadata in `checkpoint_info.json`

## API Reference

### Server Messages (JSON format)
**Request:**
```json
{
  "type": "bpy_script",
  "code": "import bpy\n# Blender code..."
}
```

**Success Response:**
```json
{
  "status": "ok",
  "details": "Code executed successfully"
}
```

**Error Response:**
```json
{
  "status": "error",
  "details": "Error message",
  "traceback": "Python traceback..."
}
```

### Core Client Library Functions
- `send_bpy_script(script_code, server_uri)`: Stuurt code naar server
- `setup_asyncio_for_windows()`: Platform-specifieke configuratie

### Dashboard API
- `BlenderWebSocketService.connect()`: Verbinding maken
- `BlenderWebSocketService.createModel()`: Model aanmaken
- `BlenderWebSocketService.getLiveModelData()`: Realtime modeldata ophalen

## Common Workflows

### 1. Nieuw Client Script Maken
```python
import asyncio, json, sys, websockets
from blender_client_lib import send_bpy_script, setup_asyncio_for_windows

async def main():
    script = """
    import bpy
    # Je Blender code hier...
    """
    await send_bpy_script(script)

if __name__ == "__main__":
    setup_asyncio_for_windows()
    asyncio.run(main())
```

## Troubleshooting & Debugging

### Server Connection Issues
- Controleer of Blender draait met de WebSocket server
- Controleer poort 8765 (niet geblokkeerd door firewall)
- Controleer websockets package installatie

### Code Execution Errors
- Check de traceback in server response
- Valideer je Blender Python code eerst in Blender zelf
- Gebruik `print()` statements in Blender code (output verschijnt in server terminal)

### Dashboard Issues
- Controleer browser console voor JavaScript fouten
- Controleer network tab voor WebSocket communicatie
- Zorg dat CORS niet blokkeert (lokale ontwikkeling)

## Performance Tips
- Gebruik binaire data voor grote modellen
- Optimaliseer Blender script voor minder geheugengebruik
- Vermijd grote for-loops in Blender code
- Gebruik batching voor multi-object operaties

## Security Considerations
- **Belangrijk**: Server voert alle ontvangen Python code uit zonder verificatie
- Alleen gebruiken in vertrouwde lokale omgeving
- Voor productie: authenticatie toevoegen (niet geïmplementeerd)
- Voor productie: API toegang beperken tot veilige operaties
