# Project Context Documentation

## Project Overview
This is a Blender automation and management system that provides a web interface for interacting with Blender through WebSocket connections. The system allows for automated 3D model creation, scene management, and real-time control of Blender instances.

## Core Components

### 1. Web Interface (`blender_web_interface.py`)
- Flask-based web application
- Provides UI for browsing and managing Blender models
- Handles model search and viewing functionality
- Serves as the main user interface for the system

### 2. Blender Agent (`blender_agent/`)
- WebSocket server implementation
- Handles communication between web interface and Blender
- Manages Blender Python script execution
- Provides real-time feedback and control

### 3. 3D Model Generation
- Various scripts for automated 3D model creation:
  - `create_3d_car.py`: Car model generator
  - `create_3d_tree.py`: Tree model generator
  - `create_3d_rings.py`: Rings model generator
- Uses Blender Python API for model creation
- Supports customization through parameters

### 4. Database Integration (`chroma_db/`)
- ChromaDB-based storage system
- Indexes and stores Blender models
- Enables efficient search and retrieval
- Maintains model metadata and relationships

### 5. Code Validation System
- Pre-commit hooks for code quality
- Custom validation rules
- Integration with Developer Guide
- Automated style checking
